# Wavecall

The landing page and the free spend planner for Wavecall, a decision helper
for *The Tower — Idle Tower Defense*.

* `index.html`   — landing page
* `planner.html` — the free planner: what your cash actually buys, by upgrade
* `costs.json`   — the game's own upgrade cost table (13 modelled upgrades)

Prices are identical for every account: workshop, cards and lab change what an
upgrade *does*, never what it *costs*. The table was checked against 94 live
measurements and all 94 matched.
